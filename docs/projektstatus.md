## Introducerade begrepp
| Begrepp | Kapitel | Kort definition |
|---|---|---|
| Greenfield | 0 | Att etablera något nytt med begränsad koppling till befintlig miljö |
| Brownfield | 0 | Att förändra eller införa något med utgångspunkt i befintlig miljö |
| Hybrid | 0 | En kombination där ny förmåga byggs samtidigt som befintliga system moderniseras stegvis |
| Containerplattform | 0 | En gemensam teknisk och organisatorisk förmåga för att köra, hantera och livscykelstyra containerbaserade applikationer |
| Plattformsförmåga | 1 | Organisationens samlade förmåga att använda, drifta, styra och vidareutveckla en gemensam plattform |
| Automatisering | 1 | Standardiserade tekniska flöden som minskar manuella moment men kräver tydligt ägarskap och förvaltning |
| Livscykelhantering | 1 | Förmågan att hantera applikationer och plattform över tid, från införande till uppdatering och avveckling |
| Plattformsteam | 1 | Team eller funktion som ansvarar för plattformens utveckling, driftstöd, standarder och användarstöd |
| Vägval | 2 | Ett strategiskt val av förändringsväg, inte bara en teknisk installationsmodell |
| Mottagande organisation | 2 | Den del av organisationen som ska ta emot, använda, drifta och vidareutveckla den nya förmågan |
| Isolerad ö | 2 | En ny lösning som fungerar tekniskt men saknar tillräcklig koppling till ordinarie styrning, drift och verksamhet |
| Dubbel komplexitet | 2 | När organisationen behöver hantera både gammal och ny miljö utan tydlig ordning, avvecklingsplan eller ansvarsfördelning |
| Styrningskrav | 3 | Formella och praktiska krav på mandat, ansvar, beslut, uppföljning och förankring |
| Säkerhetskrav | 3 | Krav som styr hur information, åtkomst, loggning, sårbarheter och regelefterlevnad ska hanteras |
| Kritisk drift | 3 | Drift av system eller tjänster där störningar kan påverka myndighetens uppdrag, säkerhet eller verksamhet |
| Formell förändringsvilja | 3 | Uttalad ambition att förändra, som behöver prövas mot faktisk tid, kompetens, mandat och prioritering |
| Systemportfölj | 4 | Samlad bild av organisationens system, deras betydelse, beroenden och lämplighet för förändring |
| Teknisk skuld | 4 | Kostnaden av tidigare val, undantag, bristande dokumentation och lösningar som blivit svåra att ändra |
| Faktisk förändringskapacitet | 4 | Det organisationen praktiskt kan genomföra utan oacceptabel påverkan på drift, säkerhet eller verksamhet |
| Kompetensrobusthet | 4 | Hur väl kompetens är spridd, dokumenterad och förankrad i team eller organisation snarare än hos enskilda personer |
| Pilotfall | 5 | Ett avgränsat första användningsfall som prövar teknik, arbetssätt, styrning, säkerhet och mottagande organisation |
| Greenfield-risk | 5 | Risk som uppstår när en ny miljö byggs utan tillräcklig koppling till organisationens verkliga ansvar och drift |
| Stoppunkt | 5 | Förutbestämd beslutspunkt där införandet omprövas om centrala förutsättningar saknas |
| Arv | 6 | Befintliga tekniska lösningar, arbetssätt, undantag och beroenden som påverkar förändringen |
| Migreringsrisk | 6 | Risken att flytt eller anpassning av befintliga system skapar driftproblem, säkerhetsproblem eller förlorad verksamhetsförmåga |
| Driftsberoende | 6 | Beroende mellan förändringsarbete och befintlig drift, exempelvis personer, rutiner, övervakning eller incidenthantering |
| Kompromissplattform | 6 | En ny plattform som försöker stödja för många gamla undantag och därför blir otydlig eller svårstyrd |
| Stegvis migrering | 7 | Att flytta eller anpassa system i en beslutad ordning utifrån risk, nytta och genomförbarhet |
| Dubbel styrning | 7 | När gammal och ny modell behöver styras parallellt under en kontrollerad övergångsperiod |
| Övergångsbrygga | 7 | En praktisk koppling mellan befintlig miljö och ny plattformsförmåga, exempelvis incidenthantering, säkerhet eller integration |
| Beslutskriterium | 8 | En bedömningsgrund som används för att jämföra greenfield, brownfield och hybrid på samma villkor |
| Viktning | 8 | Ett sätt att visa vilka kriterier som är viktigast i beslutet |
| Rekommendationslogik | 8 | Den samlade motiveringen som leder från underlag och kriterier till rekommenderat vägval |
| Spärrfråga | 8 | En kritisk fråga där ett negativt svar kräver åtgärd innan beslut genomförs |
